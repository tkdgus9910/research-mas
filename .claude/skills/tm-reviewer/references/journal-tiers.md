# 저널 Tier 판정표

Tier는 IF 하나로 정하지 않는다. **"이 저널의 리뷰어가 무엇을 요구하는가"**(요구 프로파일)로
정한다. IF·ABS 등급은 초기 배치 기준이며, 아래 수치는 2024–2025 JCR 기준 근사값이다.
불확실하면 web search로 최신 JCR IF와 분야 Q를 확인하고 "확인일"과 함께 판정 근거에 적는다.

## Tier 정의와 요구 프로파일

| | Tier 1 (Top TM/혁신) | Tier 2 (견실한 전문지) | Tier 3 (일반·국내·초기 성과) |
|---|---|---|---|
| 대표지 | Research Policy, Technovation, TFSC, JPIM, R&D Management | IEEE TEM, TASM, JETM, Scientometrics, J. Informetrics, ESWA·AEI(응용 중심) | World Patent Information, Sustainability, 대부분의 KCI지, 학회 프로시딩 |
| **A 기여** | TM/혁신 **담론에 대한 이론적·개념적 기여**가 필수. 방법 신규성만으로 부족. "어떤 TM 문제를 어떻게 다르게 풀었는가"에 답해야 함 | 명확한 방법론적 또는 실무적 기여. 기존 방법 대비 우위 입증 | 정확성·명료성 + 어느 정도의 신규성(적용 도메인 신규성도 인정) |
| **B 이론** | 선행 담론 위에 포지셔닝. 개념 도입 시 정의·근거·기존 개념과의 관계 필수 | 관련 문헌 체계적 정리, 개념 정의 명확 | 핵심 개념 정의 있으면 충분 |
| **C 방법 정당화** | 모든 기법 선택에 대안 비교 근거. 설계 선택의 민감도 | 주요 선택에 근거. 대안 언급 | 절차가 재현 가능하게 기술 |
| **D 검증** | 골드스탠다드 + 베이스라인 + 통계 검정 + 전문가 검증 + 평가자 간 신뢰도 + 다중 도메인/강건성 | 베이스라인 또는 전문가 검증 중 하나 이상 + 신뢰도 보고 | 일관된 평가 지표, 결과 재현 가능 |
| **E 결과** | 검증 나열이 아닌 **일관된 도메인 사례의 스토리텔링**. 정량 결과와 전문가 정성 논의의 상호작용 | 사례 적용과 해석 | 결과 제시와 해석 |
| **F 논의·함의** | 문헌 대비 위치, 주관성·한계의 정직한 논의, 실무자 시나리오 | 한계와 향후연구, 실무 함의 | 한계 언급 |
| **G 정합성** | 수치·용어·표 간 불일치 0. 자기모순 없음 | 불일치 소수 허용(minor) | — |
| **H 독자** | 경영·정책 연구자가 읽을 수 있어야 함(정보과학 용어 최소화) | 해당 전문 독자 | 해당 독자 |

Tier 1 안에서도 성격이 다르다:
- **Research Policy**: 이론·정책 함의가 최우선. 방법론 논문은 이론적 질문이 없으면 desk reject 수준.
- **Technovation / TFSC**: 방법론 논문에 열려 있으나 "TM 커뮤니티 기여"를 EE가 직접 묻는다.
  TFSC는 미래예측·기술평가 방법론 전통이 있어 tech mining에 우호적이지만, 정보과학 논문처럼
  읽히면 EE 단계에서 반려된다.
- **JPIM / R&D Management**: 제품혁신·R&D 관리 실무 맥락 강조. 관리적 함의가 약하면 major.

## 판정 절차

1. 저널명이 있으면 표에서 찾는다. 없으면 검색해 IF·분야·Q·ABS를 확인한다.
2. IF만 높고 심사 관행이 다른 경우(Technology in Society, 일부 MDPI)는 "IF는 A이나 요구
   프로파일은 Tier B"로 분리해 적는다. 평가 기준은 **요구 프로파일**을 따른다.
3. 저널 미지정(셀프리뷰)인 경우: 원고가 겨냥한 담론과 검증 수준을 보고 "현재 상태로 통과
   가능한 Tier"와 "저자가 겨냥한 Tier"를 둘 다 적는다. 그 간극이 곧 수정 우선순위다.
4. 판정문 형식:
   `Tier 1 — Technovation (SSCI Q1, IF ≈ 11.6 [2025 JCR, 2026-09-28 확인], ABS 3).
   적용 기준: TM 담론 기여 필수, 다중 검증 필수, 경영학 독자 가독성.`

## Tier별 결정 규칙 (scripts/recommend.py에 구현)

- **Tier 1**: A 또는 B가 2점 이하 → Reject 권고(다른 축이 높아도). D 2점 이하 → Major 이상.
  Major 조건: 어느 축이든 3점 이하 존재. Minor: 전 축 4점 이상이고 G·H만 3점. Accept: 전 축 4점 이상.
- **Tier 2**: A·B 중 하나가 1점 → Reject. C 또는 D가 2점 이하 → Major. Minor: 전 축 3점 이상,
  2개 이하 축이 3점. Accept: 전 축 4점 이상.
- **Tier 3**: G(정합성)나 C(재현 가능성)가 1점 → Reject. 3점 이하 축이 3개 이상 → Major.
  그 외 Minor. 전 축 4점 이상 Accept.
- Tier와 무관한 즉시 Reject: 연구윤리 문제, 데이터·결과 조작 의심, 범위 완전 불일치(out of scope).
