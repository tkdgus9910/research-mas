# AI스러운 방법의 유형

방법론 감사가 쓰는 기준이다. "AI스럽다"는 선행연구의 근거 없이 그럴듯하게 만들어진 방법 요소를 뜻한다. 유형 목록은 일반 기준이고, 아래 "사용자 판단 사례"가 쌓일수록 감사가 사용자 기준에 맞춰진다.

## 유형
| # | 유형 | 확인 방법 |
|---|---|---|
| 1 | 선례 없는 복합지수 | 여러 지표를 임의 가중합한 점수. 가중치와 결합 방식의 출처가 있는가 |
| 2 | 근거 없는 임계값·하이퍼파라미터 | 0.7, 상위 10% 같은 값의 출처 또는 민감도 분석이 있는가 |
| 3 | 통계·규칙으로 충분한 곳의 LLM 사용 | 같은 일을 하는 통상적 방법(빈도, 회귀, 사전 매칭, 지도학습)과 비교했는가 |
| 4 | LLM 이 LLM 출력을 평가 | 사람이 판정한 기준 표본 없이 LLM 판정만으로 품질을 주장하는가 |
| 5 | 정의 없는 신조어 | 새 지표명·프레임워크명에 정의와 기존 개념과의 관계가 있는가 |
| 6 | 근거 없는 개념 동일시 | 특허 = 기술, 토픽 = 기술 기회, 동시출현 = 융합 같은 등치에 근거가 있는가 |
| 7 | 단계 과다 | 각 단계의 기여가 검증됐는가. 여러 LLM 호출을 연쇄한 구조인가 |
| 8 | 기준선 부재 | 해당 분야의 통상적 방법과 비교한 결과가 있는가 |
| 9 | 사례 예시뿐인 검증 | 잘 나온 예시 몇 건으로 타당성을 주장하는가 |
| 10 | 과대한 일반화 표현 | 한 데이터셋의 결과로 범용 프레임워크를 주장하는가 |
| 11 | 재현 불가 요소 | 모델 버전, 프롬프트, 시드, 온도가 고정·기록되지 않았는가 |
| 12 | 자기모순 | 비판한 속성(불투명성, 비용 등)을 자기 방법이 그대로 가지는가 |
